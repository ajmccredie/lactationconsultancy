# Aga Luna Editorial Site Starter

This version is designed around the supplied Canva mock-ups: warm blush, wine/maroon typography, terracotta feature sections, elegant serif display type, restrained sans-serif text, pill CTAs, asymmetrical image-led layouts, and generous whitespace.

## Pages

- `index.html`
- `about.html`
- `services.html`
- `contact.html`

## Styles and script

- `assets/css/style.css`
- `assets/js/script.js`

## Images to add

Put final images in `assets/images/` with these exact names:

- `home-hero.jpg`
- `antenatal.jpg`
- `postnatal.jpg`
- `follow-up.jpg`
- `home-feature.jpg`
- `aga-portrait.jpg`
- `services-hero.jpg`
- `service-antenatal.jpg`
- `service-postnatal.jpg`
- `service-follow-up.jpg`
- `contact-hero.jpg`

The CSS is already wired to these filenames.

When the images are in place, remove the little `<span class="image-note">...</span>` labels from the HTML.

## Before launch

1. Replace placeholder service/pricing copy with Aga's approved wording.
2. Replace `YOUR_FORM_ID` in `contact.html` with the Formspree endpoint.
3. Add real Instagram/Facebook links.
4. Confirm email and WhatsApp details.
5. Add favicon and social-sharing image.
6. Add `404.html`, `robots.txt`, and `sitemap.xml`.
7. Test keyboard navigation, mobile sizes and Formspree submission.
8. Connect the custom domain only after GitHub Pages is working on its temporary URL.

## Fonts

The starter uses:
- Cormorant Garamond — display/headings
- Montserrat — body/navigation

Both are loaded from Google Fonts. They can easily be changed later.

## Main colour variables

Edit these at the very top of `assets/css/style.css`:

```css
--wine: #78162e;
--terracotta: #a45f50;
--blush: #e6d7ce;
--cream: #fffaf6;
```
